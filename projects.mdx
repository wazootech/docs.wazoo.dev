Wazoo maintains an ecosystem of independent open-source projects. While
**Wazoo** powers hosted verifiable context infrastructure, these child projects
exist as standalone libraries, CLI tools, specs, and adapters that developers
can use independently.

<CardGroup cols={2}>

## Ecosystem Repositories

Each repository is independently versioned and published:

| Project                    | Repository                                                              | Scope & Description                                       |
| :------------------------- | :---------------------------------------------------------------------- | :-------------------------------------------------------- |
| **Wazoo SDK**              | [`wazoo-client-ts`](https://github.com/wazootech/wazoo-client-ts)       | Primary TypeScript client for Platform API management     |
| **Worlds Client**          | [`worlds-client-ts`](https://github.com/wazootech/worlds-client-ts)     | Graph engine client & embedded in-memory database         |
| **Worlds Adapters**        | [`worlds-libsql`](https://github.com/wazootech/worlds-libsql)           | Storage adapters for LibSQL / Turso                       |
| **Wiki Toolchain**         | [`wiki`](https://github.com/wazootech/wiki)                             | Semantic Markdown validator and static generator          |
| **Linked Markdown**        | [`linked-markdown`](https://github.com/wazootech/linked-markdown)       | Specification & conformance suite for semantic Markdown   |
| **Linked Markdown TS**     | [`linked-markdown-ts`](https://github.com/wazootech/linked-markdown-ts) | TypeScript parser & AST transformer                       |
| **Linked Markdown Python** | [`linked-markdown-py`](https://github.com/wazootech/linked-markdown-py) | Python implementation of Linked Markdown                  |
| **MemSDK**                 | [`memsdk`](https://github.com/wazootech/memsdk)                         | Portable memory interface for agent framework integration |
| **MemSDK Adapters**        | [`memsdk-worlds`](https://github.com/wazootech/memsdk-worlds)           | Native MemSDK driver for Wazoo Worlds                     |

[Codex](https://developers.openai.com/codex/) is OpenAI's coding agent,
available as a CLI and an IDE extension. Codex reads Agent Skills from
`.agents/skills/` in project scope, so it connects to Wazoo through the
[`wazoo` skill](/skills/wazoo) from
[wazootech/wazoo-skills](https://github.com/wazootech/wazoo-skills).

<Warning>
  **Experimental Integration** The official Worlds capabilities for this
  framework are under active development. Expect API friction and missing
  language parity.
</Warning>

## Requirements

- A platform token (`wzp_...`) for control-plane operations and a world token
  (`wzw_...`) for data-plane operations. Mint both in the console (see
  [tokens](/console/tokens)).

## Install the skill

From your project root:

```bash
npx skills add wazootech/wazoo-skills --skill=wazoo -y
```

This copies the skill to `.agents/skills/wazoo/SKILL.md`, which Codex reads
directly. The same location serves other agents (Cursor, OpenCode, and more), so
one install covers the whole toolkit. Commit `.agents/` and `skills-lock.json`
so teammates get the same capability. Update with:

```bash
npx skills update wazoo
```

## Set the tokens

The skill drives two REST surfaces through environment variables:

```bash
export WAZOO_PLATFORM_TOKEN="wzp_..." # control plane: worlds, tokens, usage
export WORLDS_TOKEN="wzw_..." # data plane: import, search, SPARQL, export
```

## What the agent can do

Once installed, the skill instructs the agent how to manage worlds, import
Turtle, run SPARQL, and search. The underlying calls are the same surfaces
documented in [Worlds](/worlds/index): [import](/worlds/update),
[search](/worlds/search), and [SPARQL queries](/worlds/query).

For the full command reference, see [the `wazoo` skill docs](/skills/wazoo).

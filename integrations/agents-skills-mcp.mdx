## Overview

AI agents interact with Wazoo memory across two primary API planes:

- **Control plane** (`api.wazoo.dev`): Manage worlds, API keys, and account resources using `WAZOO_PLATFORM_TOKEN` (`wzp_`).
- **Data plane** (`worlds-api.wazoo.dev`): Perform [import](/worlds/update), [hybrid search](/worlds/search), [pattern queries](/worlds/query), and export using `WORLDS_TOKEN` (`wzw_`).

The Model Context Protocol (MCP) and Agent Skills standard provide native mechanisms for AI tools (Claude Code, Cursor, OpenCode, Gemini, etc.) to command these APIs seamlessly.

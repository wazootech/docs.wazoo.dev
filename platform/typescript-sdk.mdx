`@wazoo/client` is the primary TypeScript SDK for the
[Wazoo Platform API](/platform/api). It provides a typed interface for managing
your Wazoo infrastructure: provisioning Worlds, managing API tokens (`wzp_` and
`wzw_`), and tracking resource usage and billing.

## Quickstart

The client does not read environment variables on its own. Create a client that
points at the platform API and pass your platform token explicitly:

```typescript
import { createClient, listWorlds } from "@wazoo/client";

const client = createClient({
  baseUrl: "https://api.wazoo.dev",
  auth: process.env.WAZOO_PLATFORM_TOKEN,
});

const { data, error } = await listWorlds({ client });
console.log(data?.worlds);
```

Platform tokens require the `wzp_` prefix. Without `auth`, every call returns
`401 UNAUTHENTICATED`.

## Worlds

```typescript
import {
  createWorld,
  getWorld,
  listWorlds,
  updateWorld,
  deleteWorld,
  createClient,
} from "@wazoo/client";

const client = createClient({
  baseUrl: "https://api.wazoo.dev",
  auth: process.env.WAZOO_PLATFORM_TOKEN,
});

// List active worlds
const { data } = await listWorlds({ client });
console.log(data?.worlds);

// Create a world
const created = await createWorld({
  client,
  body: {
    world: { displayName: "Support Knowledge", region: "auto" },
  },
});
const worldId = created.data!.world.id;

// Get a world by ID
const world = await getWorld({
  client,
  path: { worldId },
});

// Update display name
await updateWorld({
  client,
  path: { worldId },
  body: {
    updateMask: "displayName",
    world: { displayName: "Support Knowledge Base" },
  },
});

// Soft-delete (recoverable for 30 days)
await deleteWorld({ client, path: { worldId } });
```

`world.id` is the immutable `w_<ULID>` ID minted by the Worlds API. Reuse it
unchanged as the `worldId` path value.

Creating a platform world provisions per-World graph storage. Use
`data.wazoo.dev`, the generated [`@worlds/client`](/projects/worlds), or the
embedded [`@worlds/sdk`](/projects/worlds) for graph data operations inside that
world. See [Platform API](/platform/api#data-plane-boundary) for the hosted
architecture.

## Platform API tokens

```typescript
import {
  createClient,
  listPlatformTokens,
  createPlatformToken,
  deletePlatformToken,
} from "@wazoo/client";

const client = createClient({
  baseUrl: "https://api.wazoo.dev",
  auth: process.env.WAZOO_PLATFORM_TOKEN,
});

// List tokens
const { data } = await listPlatformTokens({ client });

// Create a token (secret shown once)
const created = await createPlatformToken({
  client,
  body: {
    name: "my-read-token",
    scope: "users.read worlds.read usage.read",
  },
});
console.log(created.data?.token); // wzp_...

// Revoke a token by name
await deletePlatformToken({ client, path: { tokenName: "my-read-token" } });
```

## World auth tokens

World data-plane tokens use the `wzw_` prefix. They are scoped to a single
namespace and optionally a single world.

```typescript
import {
  createClient,
  listWorldTokens,
  createWorldToken,
  deleteWorldToken,
} from "@wazoo/client";

const client = createClient({
  baseUrl: "https://api.wazoo.dev",
  auth: process.env.WAZOO_PLATFORM_TOKEN,
});

const { data } = await listWorldTokens({
  client,
  path: { worldId },
});

const created = await createWorldToken({
  client,
  path: { worldId },
});
console.log(created.data?.token); // one-time secret

await deleteWorldToken({
  client,
  path: { worldId, tokenUid: created.data!.token.uid },
});
```

## Usage and limits

```typescript
import { createClient, getWorldUsage, getWorldLimits } from "@wazoo/client";

const client = createClient({
  baseUrl: "https://api.wazoo.dev",
  auth: process.env.WAZOO_PLATFORM_TOKEN,
});

const usage = await getWorldUsage({
  client,
  path: { worldId },
});
console.log(usage.data?.usage.total);

const limits = await getWorldLimits({
  client,
  path: { worldId },
});
```

## Billing

```typescript
import { getWorldBilling } from "@wazoo/client";

const billing = await getWorldBilling({
  path: { worldId },
});
console.log(billing.data?.billing.state);
```

## Custom client configuration

By default, SDK functions automatically use the built-in client. You can
configure global defaults or create isolated custom client instances:

```typescript
import { client, createClient, listWorlds } from "@wazoo/client";

// Configure default client globally (e.g. set global headers or custom token)
client.setConfig({
  auth: process.env.CUSTOM_PLATFORM_TOKEN,
});

// Or create an isolated client instance for multi-tenant setups
const customClient = createClient({
  baseUrl: "https://api.wazoo.dev",
  auth: "wzp_custom_token",
});

const { data } = await listWorlds({ client: customClient });
```

## Error handling

The SDK returns a discriminated union by default:

```typescript
const r = await listWorlds();
if (r.error) {
  console.error(r.error.error.code, r.error.error.message);
} else {
  console.log(r.data?.worlds);
}
```

Set `throwOnError: true` on the client for exception-based handling.

## Runtime

The SDK is a fetch-based ESM package published on JSR. It runs in any modern
JavaScript runtime that provides `fetch`: Node.js, Cloudflare Workers, Deno,
Bun, and browsers.

  reindex, and search with hybrid ranking."

<Warning>
  This guide describes the Platform API as proposed in
  [wazootech/wazoo-api#123](https://github.com/wazootech/wazoo-api/issues/123).
  The `/v1/users/me/embedding-providers` endpoints are not live yet. Do not
  publish this page until they ship.
</Warning>

By default, search in a world is keyword search. With bring-your-own-key (BYOK)
embeddings, Worlds also builds vector embeddings of a world's text with your
embedding provider account, and search combines both rankings. Paraphrases and
questions that share no words with the stored text can then find the right
entity. See [Search](/worlds/search) for how the rankings merge.

You pay the provider directly for the embedding calls. Wazoo stores your key
encrypted, never returns it, and uses it only to embed the text of your own
worlds.

## Providers and models

A namespace holds one key per provider. The model you choose for a world decides
which provider's key is used.

| Provider   | Model id                                   | Notes                      |
| :--------- | :----------------------------------------- | :------------------------- |
| OpenAI     | `openai/text-embedding-3-small`            | Recommended starting point |
| OpenAI     | `openai/text-embedding-3-large`            | Sent at 1536 dimensions    |
| OpenRouter | `openrouter/openai/text-embedding-3-small` | Billed through OpenRouter  |
| OpenRouter | `openrouter/openai/text-embedding-3-large` | Sent at 1536 dimensions    |

All vectors are 1536 dimensions wide, so a model is only available if it can
produce that width. Other models are not accepted.

## Prerequisites

- A Wazoo platform token (`wzp_`) from the [Console](https://console.wazoo.dev).
  See [Tokens](/console/tokens).
- A world and a world token (`wzw_`) for it.
- An account and API key with an embedding provider. Set a monthly spend limit
  on the key.

<Steps>
  <Step title="Store your provider key">
    Send the key to the Platform API with your platform token. The key is
    write-only: no endpoint ever returns it.

    ```bash title="Store an OpenAI key"
    curl -s -X PUT "https://api.wazoo.dev/v1/users/me/embedding-providers/openai" \
      -H "Authorization: Bearer $WAZOO_PLATFORM_TOKEN" \
      -H "Content-Type: application/json" \
      -d '{ "apiKey": "'"$OPENAI_API_KEY"'" }'
    ```

    For OpenRouter, use `openrouter` in the path and your OpenRouter key.

    The response shows metadata only:

    ```json title="Response"
    {
      "provider": "openai",
      "status": "active",
      "fingerprint": "3f9a1c2e",
      "last4": "Zq4w",
      "createTime": "2026-10-19T14:02:11.000Z"
    }
    ```

    The key must be 16 to 512 printable characters with no whitespace.

  </Step>
  <Step title="Choose a model for a world">
    Set the model on the world with its world token. Choosing a model requires
    an active key for that model's provider.

    ```bash title="Choose a model"
    curl -s -X PATCH "https://data.wazoo.dev/worlds/w_01jd8x5mqv7k3n9r2t4w6y8z0b" \
      -H "Authorization: Bearer $WORLDS_TOKEN" \
      -H "Content-Type: application/json" \
      -d '{ "embeddingModel": "openai/text-embedding-3-small" }'
    ```

    The world's `embeddingStatus` becomes `stale`. Search stays keyword-only
    until you reindex.

  </Step>
  <Step title="Reindex the world">
    Reindexing embeds the world's text with your key and spends your provider
    budget. It does not run automatically.

    ```bash title="Reindex"
    curl -s -X POST "https://data.wazoo.dev/worlds/w_01jd8x5mqv7k3n9r2t4w6y8z0b/reindex" \
      -H "Authorization: Bearer $WORLDS_TOKEN"
    ```

    The response `status` is one of:

    | Status                         | Meaning                                                                                  |
    | :----------------------------- | :--------------------------------------------------------------------------------------- |
    | `completed`                    | All vectors are built.                                                                   |
    | `completed_with_vector_errors` | Some vectors failed. `vectorSync` lists what. Call reindex again to retry.                |
    | `in_progress`                  | A large world reindexes in windows. Call reindex again until the status is `completed`. |

    Indexing is eventually consistent. When reindex reports `completed`, your
    vectors are written, but search can take a minute or more to start using
    them. Until then search stays keyword-only, so results still return.

  </Step>
  <Step title="Check the world's status">
    ```bash title="Read the world"
    curl -s "https://data.wazoo.dev/worlds/w_01jd8x5mqv7k3n9r2t4w6y8z0b" \
      -H "Authorization: Bearer $WORLDS_TOKEN"
    ```

    Read `embeddingStatus` in the response:

    | Value           | Meaning                                                              |
    | :-------------- | :------------------------------------------------------------------- |
    | `ready`         | Vectors are current. Search is hybrid.                               |
    | `stale`         | Vectors are not built for the current model. Reindex.                |
    | `partial`       | Some vectors failed. Hybrid search covers what exists. Reindex.      |
    | `no_credential` | There is no active key for this model's provider. Store one.         |
    | `invalid`       | The provider rejected your key. Store a new key.                     |
    | `unconfigured`  | The world has no allowlisted embedding model. Choose one.            |

  </Step>
  <Step title="Search">
    ```bash title="Search"
    curl -s -X POST "https://data.wazoo.dev/worlds/w_01jd8x5mqv7k3n9r2t4w6y8z0b/search" \
      -H "Authorization: Bearer $WORLDS_TOKEN" \
      -H "Content-Type: application/json" \
      -d '{ "query": "who does Gregory report to?", "limit": 5 }'
    ```

    The response `mode` is `hybrid` when vectors were used and `keyword` when
    search fell back to full-text only. A query that shares no words with the
    stored text, such as a paraphrase, returns results only in `hybrid` mode.
    If `mode` is still `keyword` right after a reindex, wait a minute and
    search again.

  </Step>
</Steps>

## List, rotate, and revoke keys

List the keys a namespace holds. Revoked keys stay in the list so their status
stays readable:

```bash title="List providers"
curl -s "https://api.wazoo.dev/v1/users/me/embedding-providers" \
  -H "Authorization: Bearer $WAZOO_PLATFORM_TOKEN"
```

To rotate a key, send the same `PUT` with the new key.

To revoke a key, delete it:

```bash title="Revoke a key"
curl -s -X DELETE "https://api.wazoo.dev/v1/users/me/embedding-providers/openai" \
  -H "Authorization: Bearer $WAZOO_PLATFORM_TOKEN"
```

Revoking erases the stored key. Every world that uses that provider's models
becomes `stale` and falls back to keyword search. Worlds on another provider's
models are not affected. After you store a new key, reindex each world before
hybrid search returns. Vectors built before a revoke are never reused.

## Cost and limits

- Reindexing and importing text call your provider and bill your account. A
  retry after a transient provider error is billed again.
- Each namespace has a daily limit on embedding writes. When it is exhausted,
  reindex returns `429` with the code `EMBEDDING_BUDGET_EXCEEDED` and nothing is
  embedded or billed.
- Searching embeds only the query text. Search falls back to keyword results if
  the provider is slow or unavailable.

## Troubleshooting

| Symptom                                              | Cause and fix                                                                                                  |
| :--------------------------------------------------- | :------------------------------------------------------------------------------------------------------------- |
| `409` with `EMBEDDING_CREDENTIAL_REQUIRED` on step 2 | You have no active key for the model's provider. Store one in step 1.                                          |
| `400` when storing a key                             | The key has whitespace or is outside 16 to 512 characters, or the provider is not `openai` or `openrouter`.    |
| `503` with `EMBEDDINGS_NOT_CONFIGURED`               | Embeddings are not enabled on this deployment. Contact the team.                                               |
| `embeddingStatus` is `invalid`                       | Your provider rejected the key several times in a row. Check the key and its spend limit, then store it again. |
| Search `mode` stays `keyword` after reindex          | Wait a minute or two, because indexing is eventually consistent. If it persists, check `embeddingStatus`: anything other than `ready` or `partial` keeps search keyword-only. |
| `completed_with_vector_errors`                       | Call reindex again. The `vectorSync.errors` list names the failures.                                           |

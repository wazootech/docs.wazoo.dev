This glossary defines technical terms, standards, and concepts used throughout
Wazoo documentation, APIs, and SDKs.

## Knowledge Graph & RDF Concepts

### RDF (Resource Description Framework)

**RDF**: A W3C standard framework for representing information about resources on the web
using Subject-Predicate-Object triples.

### SPARQL

**SPARQL**: A declarative query language and protocol for RDF graph databases. SPARQL allows
agents to perform deterministic graph traversals and pattern matching.

### Triple / Quad

The foundational unit of RDF data:

- **Triple**: Subject, Predicate, Object (e.g. `ex:Agent ex:uses ex:Worlds`).
- **Quad**: A triple bound to a named graph context (Subject, Predicate, Object,
  Graph/World ID).

### SHACL (Shapes Constraint Language)

**SHACL**: A W3C standard language for validating RDF graphs against specified shapes and
constraints.

## Neuro-Symbolic AI & Memory

### Context Engine

**Context Engine**: A specialized system that combines structured knowledge graph querying with
vector similarity search to provide precise, verifiable context to AI models.

### Reciprocal Rank Fusion (RRF)

**Reciprocal Rank Fusion (RRF)**: An algorithmic technique used by Worlds to fuse search rankings from multiple
retrieval signals (pattern queries, full-text search, and vector
embeddings) into a single, optimized rank list.

### Provenance

**Provenance**: The immutable, auditable lineage of facts stored in Worlds, tracking the exact
source, timestamp, and context of every quad assertion.

## Wazoo Ecosystem

### Worlds

**Worlds**: The authoritative context engine and RDF fact ledger platform built by Wazoo
Technologies.

### MemSDK

**MemSDK**: A backend-agnostic TypeScript SDK interface that standardizes memory operations
(add, search, profile, forget) across multiple memory backends.

### Wazoo Skill

**Wazoo Skill**: The official skill package ([wazootech/wazoo-skills](https://github.com/wazootech/wazoo-skills)) that equips AI coding
agents with decision mapping and memory context tools.

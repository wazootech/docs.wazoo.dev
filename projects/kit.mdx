---
title: "WorldsKit"
description:
  "React and UI component kit for building Wazoo Worlds memory experiences."
---

`@worlds/kit` provides UI components, React hooks, and state utilities for
embedding Wazoo Worlds context, graph visualization, and memory management into
web applications.

## Key Features

- **React Components**: Pre-built memory search, fact views, and graph
  inspectors.
- **State Hooks**: Reactive hooks for loading, querying, and mutating worlds
  memory.
- **Framework Integration**: Designed for modern TypeScript and React stacks.

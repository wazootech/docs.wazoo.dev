`wazoo-skills` is the official repository for Wazoo skills. It provides agent
skill definitions, setup commands, and distribution patterns for AI pair
programmers and CLI tools.

## Key features

- **Standardized skill definitions**: Clean `SKILL.md` frontmatter and
  instruction layers following Wazoo customization patterns.
- **Cross-environment compatibility**: Supports Claude Code, OpenCode, Codex,
  and agentic workflows.
- **Easy installation**: Add skills using the `skills` CLI runner across npm,
  pnpm, yarn, and bun.

## Available skills

| Skill                    | Description                                       | Quickstart                                            |
| :----------------------- | :------------------------------------------------ | :---------------------------------------------------- |
| [`wazoo`](/skills/wazoo) | AI agent context integration and decision mapping | `npx skills add wazootech/wazoo-skills --skill=wazoo` |

## Installation

Install skills into your local agent environment:

<CodeGroup>

```bash npm
npx skills add wazootech/wazoo-skills --skill=wazoo
```

```bash pnpm
pnpm dlx skills add wazootech/wazoo-skills --skill=wazoo
```

```bash yarn
yarn dlx skills add wazootech/wazoo-skills --skill=wazoo
```

```bash bun
bunx skills add wazootech/wazoo-skills --skill=wazoo
```

</CodeGroup>

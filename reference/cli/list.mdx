---
title: "wazoo worlds list"
description: "List all worlds owned by your account"
---

The `wazoo worlds list` command retrieves all World instances owned by your
authenticated account. See [Worlds](/worlds/index) for what a world contains.

## Usage

```bash
wazoo worlds list [options]
```

## Examples

### List all worlds

```bash
wazoo worlds list
```

### List worlds as JSON

```bash
wazoo worlds list --json
```

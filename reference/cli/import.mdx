---
title: "wazoo worlds import"
description: "Import raw text, file, or RDF data into a world"
---

The `wazoo worlds import` command imports raw text content, files, or RDF statements directly into a target world context.

## Usage

```bash
wazoo worlds import <worldId> [options]
```

## Parameters & Options

| Argument / Option | Description |
| :--- | :--- |
| `<worldId>` | **Required.** Target world ID |
| `-f, --file <filePath>` | Path to local file to import |
| `-d, --data <text>` | Inline string text content to import |
| `-t, --type <contentType>` | Content type header (default: `text/plain`) |

## Examples

### Import from a local file

```bash
wazoo worlds import my-world --file ./data.ttl --type text/turtle
```

### Import inline text data

```bash
wazoo worlds import my-world --data "Alice is a software engineer."
```

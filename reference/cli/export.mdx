---
title: "wazoo worlds export"
description: "Export world graph quads/triples"
---

The `wazoo worlds export` command exports statements and quads from a target
world graph. Export complements [import](/worlds/update) as the read path for
graph data.

## Usage

```bash
wazoo worlds export <worldId> [options]
```

## Parameters & Options

| Argument / Option      | Description                                 |
| :--------------------- | :------------------------------------------ |
| `<worldId>`            | **Required.** Target world ID               |
| `--format <fmt>`       | Export format (default: `application/json`) |
| `-l, --limit <number>` | Maximum quads to export (default: `100`)    |

## Examples

### Export graph data as JSON

```bash
wazoo worlds export my-world --limit 50
```

---
title: "wazoo worlds create"
description: "Create a new isolated memory world"
---

The `wazoo worlds create` command provisions a new persistent World instance on
the server.

## Parameters & Options

| Option                     | Description                                             |
| :------------------------- | :------------------------------------------------------ |
| `-w, --world-id <worldId>` | **Required.** World resource identifier string          |
| `-n, --name <displayName>` | **Required.** Human-readable display name for the world |

## Usage

```bash
wazoo worlds create -w my-world -n "My First World"
```

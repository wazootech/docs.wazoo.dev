---
title: "wazoo worlds sparql"
description: "Execute raw SPARQL queries against a world graph"
---

The `wazoo worlds sparql` command executes SPARQL 1.1 graph queries directly
against a world's knowledge graph endpoint.

## Usage

```bash
wazoo worlds sparql <worldId> [options]
```

## Parameters & Options

| Argument / Option           | Description                                |
| :-------------------------- | :----------------------------------------- |
| `<worldId>`                 | **Required.** Target world ID              |
| `-q, --query <sparqlQuery>` | Inline SPARQL query string                 |
| `-f, --file <filePath>`     | Path to `.rq` file containing SPARQL query |

## Examples

### Inline SPARQL query

```bash
wazoo worlds sparql my-world -q "SELECT * WHERE { ?s ?p ?o } LIMIT 10"
```

### SPARQL query from file

```bash
wazoo worlds sparql my-world -f ./queries/get_users.rq
```

---
title: "wazoo worlds search"
description: "Hybrid vector and graph search across world memory"
---

The `wazoo worlds search` command performs semantic hybrid search across vector
embeddings and knowledge graph triples stored within a world. For how the search
index works, see [Search](/worlds/search).

## Usage

```bash
wazoo worlds search <worldId> -q <query> [options]
```

## Parameters & Options

| Argument / Option      | Description                                           |
| :--------------------- | :---------------------------------------------------- |
| `<worldId>`            | **Required.** Target world ID                         |
| `-q, --query <text>`   | **Required.** Natural language or vector search query |
| `-l, --limit <number>` | Maximum number of results to return (default: `5`)    |

## Examples

### Search for relevant memory context

```bash
wazoo worlds search my-world -q "Acme Corp operations" --limit 10
```

---
title: "wazoo worlds get"
description: "Retrieve a specific world by ID"
---

The `wazoo worlds get` command retrieves structural details, metadata, and
creation timestamps for a single target world instance.

## Usage

```bash
wazoo worlds get <worldId>
```

## Parameters

| Parameter   | Description                                             |
| :---------- | :------------------------------------------------------ |
| `<worldId>` | **Required.** The unique identifier of the target world |

## Examples

```bash
wazoo worlds get my-world
```

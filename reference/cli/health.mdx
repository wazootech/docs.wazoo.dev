---
title: "wazoo health"
description: "Check status and health of the Wazoo API service"
---

The `wazoo health` command verifies connectivity and operational status of the Wazoo API platform.

## Usage

```bash
wazoo health [options]
```

## Options

| Option | Description |
| :--- | :--- |
| `--api-url <url>` | Wazoo API base URL (overrides `WAZOO_API_URL`) |
| `--token <token>` | API token override |
| `--json` | Return structured JSON output |

## Examples

### Check API health

```bash
wazoo health
```

### Check health with JSON output

```bash
wazoo health --json
```

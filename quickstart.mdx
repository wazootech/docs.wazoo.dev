Wazoo helps agents and applications work with context as structured, verifiable,
portable data instead of opaque text blobs.

## The mental model

Wazoo starts from a simple sequence:

- Author context in Markdown when humans need to read and maintain it.
- Add typed frontmatter when machines need to validate and query it.
- Load verified facts into worlds when agents need graph search and traversal.
- Use portable memory interfaces when applications need to swap memory backends.

The projects share this model, but each one starts at a different layer.

## Platform and data APIs

Hosted Wazoo separates management operations from graph data operations:

- Use the [Wazoo Platform API](/platform/api) or `@wazoo/api` to manage
  user-owned Worlds, tokens, and usage.
- Use the Worlds Data API or `@worlds/client` to import RDF, export RDF, search,
  run SPARQL, and update graph state.

Platform tokens use the `wzp_` prefix. World tokens use the `wzw_` prefix. Keep
them separate.

## Quickstart with cURL and API keys

If you prefer calling the Wazoo Platform API directly using HTTP/cURL:

<Steps>
  <Step title="Get your platform token">
    Generate your `wzp_` token from [console.wazoo.dev](https://console.wazoo.dev) under **Tokens**.
  </Step>
  <Step title="List your worlds">
    ```bash
    curl -s -X GET "https://api.wazoo.dev/v1/worlds" \
      -H "Authorization: Bearer wzp_YOUR_PLATFORM_TOKEN"
    ```
  </Step>
  <Step title="Create a new world">
    ```bash
    curl -s -X POST "https://api.wazoo.dev/v1/worlds" \
      -H "Authorization: Bearer wzp_YOUR_PLATFORM_TOKEN" \
      -H "Content-Type: application/json" \
      -d '{
        "worldId": "my-agent-world",
        "world": {
          "displayName": "My Agent World",
          "region": "auto"
        }
      }'
    ```
  </Step>
</Steps>

## Agent skills (`SKILL.md`)

Agent skills allow AI coding agents (Claude Code, Cursor, OpenCode, Antigravity)
to query and manage Wazoo memory directly. A skill consists of a `SKILL.md` file
located inside `.agents/skills/<skill-name>/SKILL.md` (or
`~/.gemini/config/skills/`).

### How AI agents access the API via `SKILL.md`

Your `SKILL.md` equips the agent with instructions and terminal command patterns
(cURL or CLI) to read and write context:

````markdown
---
name: wazoo-memory
description: Read and write persistent knowledge and memories in Wazoo Worlds.
---

# Wazoo Memory Skill

Use this skill when saving durable context, user preferences, or project
decisions to Wazoo.

## Environment setup

Ensure `WAZOO_PLATFORM_TOKEN` (starts with `wzp_`) is exported in your
environment.

## 1. List active worlds

```bash
curl -s -X GET "https://api.wazoo.dev/v1/worlds" \
  -H "Authorization: Bearer $WAZOO_PLATFORM_TOKEN"
```

## 2. Store context in a world

```bash
curl -s -X POST "https://api.wazoo.dev/v1/worlds" \
  -H "Authorization: Bearer $WAZOO_PLATFORM_TOKEN" \
  -H "Content-Type: application/json" \
  -d '{
    "worldId": "project-context",
    "world": { "displayName": "Project Context Graph" }
  }'
```
````

To install, simply place the skill folder in your project's
`.agents/skills/wazoo-memory/SKILL.md` or global agent configuration directory.

## Quickstart with cURL and API keys

If you prefer calling the Wazoo Platform API directly using HTTP/cURL:

<Steps>
  <Step title="Get your platform token">
    Generate your `wzp_` token from the
    [Console tokens page](/console/tokens).
  </Step>
  <Step title="List your worlds">
    ```bash
    curl -s -X GET "https://api.wazoo.dev/v1/worlds" \
      -H "Authorization: Bearer wzp_YOUR_PLATFORM_TOKEN"
    ```
  </Step>
  <Step title="Create a new world">
    ```bash
    curl -s -X POST "https://api.wazoo.dev/v1/worlds" \
      -H "Authorization: Bearer wzp_YOUR_PLATFORM_TOKEN" \
      -H "Content-Type: application/json" \
      -d '{
        "worldId": "my-agent-world",
        "world": {
          "displayName": "My Agent World",
          "region": "auto"
        }
      }'
    ```
  </Step>
</Steps>

## Agent skills (`SKILL.md`)

Agent skills allow AI coding agents (Claude Code, Cursor, OpenCode, Antigravity)
to query and manage Wazoo memory directly.

Wazoo publishes a `wazoo` skill through Agent Skills Discovery at
[docs.wazoo.dev](https://docs.wazoo.dev). Install it into your local agent
environment:

```bash
npx skills add https://docs.wazoo.dev -g -y
```

For the full agent-operational skill (world and token lifecycle across the
control and data planes), manually place
[`SKILL.md`](https://docs.wazoo.dev/skills/wazoo/SKILL.md) inside
`.agents/skills/wazoo/SKILL.md` (or `~/.gemini/config/skills/`).

The manual skill reads `WAZOO_PLATFORM_TOKEN` (`wzp_`) and `WORLDS_TOKEN`
(`wzw_`) from your environment. It covers the full lifecycle for worlds and
tokens: list, create, read, update, delete, undelete, search, import, and
export.

New to Wazoo? Start with the [getting started guide](/getting-started) for an
end-to-end walkthrough from invite to your first query.
